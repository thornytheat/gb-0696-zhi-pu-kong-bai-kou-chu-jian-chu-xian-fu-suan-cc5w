# 质谱字段与规则

sample_id保留前导零。kind取standard、blank、sample、control。area与internal_area为峰面积。level为标样浓度，单位支持ug/L、mg/L、ng/L；统一为ug/L。dilution必须大于0。

每批每检测项至少3个独立浓度点。最小二乘使用Decimal，分母为零拒绝；斜率非正拒绝。控制样相对误差超过20%阻断。超过标曲响应范围优先于其他质控判断。

## 空白

空白按进样顺序逐个建档：空白浓度= (响应比−截距) / 斜率。

- `CLEAN` 洁净空白可计入批中位数。
- `CARRYOVER` 紧跟最高标样之后、浓度显著抬升的空白，归因为进样带出；不进入批中位数，但保留来源行，可作降级基线。
- `UNKNOWN_HIGH` 没有高标样前因的抬升空白，来源不明，记为隔离记录并阻断整批放行。

抬升阈值逐条留一计算：取「其余空白的中位数+3MAD」与「最低正校准点×20%」中的较小者；其余空白少于3个时只用后者。最高标样指≥最高正校准点×80%的标样。

批空白取同批同项洁净空白（无洁净空白时可退化为残留空白）的浓度中位数。净浓度允许为负；不能提前截零。稀释后检出限=0.05×倍数。

## 低浓度样品的相邻空白

原始浓度（未扣空白）不高于最低正校准点的样品为低浓度样品，改用进样顺序上最近的已注入空白扣除，以控制进样漂移：

- 相邻空白为 `CLEAN` 或 `CARRYOVER` 时切换生效（`APPLIED`）。
- 相邻空白无效、被隔离或不存在时切换失败（`KEPT_ORIGINAL`），保留批中位数原结论。
- 控制样与高浓度样品始终使用批中位数。

## 结论与证据

每个样品只产生一条最终检出结论：低于检出限或净浓度为负=未检出，超范围=超范围需复核，控制样超差=质控失败，其余=检出。限定符`<`表示低于检出限。

证据导出中`kind=result`每样一行只含最终结论；`kind=amendment`保留切换前后两次空白、浓度、结论与限定符；`kind=blank`保留每个空白的来源行与归类；`kind=quarantine`保留隔离原因。同一序列重跑按摘要幂等，不重复追加修正记录。

## 其他

重复编号相同内容标DUPLICATE，不同内容标KEY_CONFLICT。采信包括标曲和空白，最终样品数不等于输入采信数。行数对账独立于样品结果数。

同一批次同一分析项内sample_id唯一；相同样品编号可在不同分析项或批次中复用。
